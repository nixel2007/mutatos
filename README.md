# mutatos

Мутационное тестирование для [OneScript](https://oscript.io) в духе [pitest](https://pitest.org).

`mutatos` вносит небольшие изменения (мутации) в исходный код библиотеки — меняет `+` на `-`,
`<` на `<=`, `Истина` на `Ложь` — и прогоняет тесты [OneUnit](https://github.com/nixel2007/OneUnit).
Если тесты проходят на мутированном коде — мутант «выжил», а значит, тесты не проверяют
это поведение. Доля «убитых» мутантов (mutation score) — куда более честная метрика качества
тестов, чем построчное покрытие.

## Статус

Проект на стадии проектирования. Архитектура и план развития — в [docs/design.md](docs/design.md).

## Планируемое использование

```console
$ mutatos run --src ./src --tests ./tests
...
Мутационное тестирование завершено.
  Мутантов сгенерировано: 184
  Убито:                  151 (82%)
  Выжило:                 21
  Таймаут:                4
  Нежизнеспособных:       6
  Без покрытия:           2
```

## Стек

- [osparser](https://github.com/oscript-library/osparser) — разбор исходников и точечные замены (мутации);
- [OneUnit](https://github.com/nixel2007/OneUnit) — прогон тестов и получение покрытия;
- [autumn](https://github.com/autumn-library/autumn) + autumn-cli — каркас приложения.
